A theme's list of what it loads from other sites, and the head code a site that asks visitors first holds back, now see `@import` written with no space after it, CSS escapes and `image-set()`. Editors' limits count what a page translates only for a page in another language translating one in the main language. `goodfellow preview` answers requests only by `localhost` or an IP address, as `goodfellow dev` does, so a website can't point its own name at this computer to read it; only this computer can open it, as before, unless `--network` is given. WordPress exports write a Heading's alignment only where it's one WordPress has. WordPress exports, imports and pastes no longer stop at a linked file whose address has a stray `%` in it: they name it by its address as written.
