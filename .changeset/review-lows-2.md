A theme's list of what it loads from other sites, and the head code a site that asks visitors first holds back, now see `@import` written with no space after it, CSS escapes and `image-set()`. Editors' limits count what a page translates only for a page in another language translating one the main language has, and only one such page in each language. `goodfellow preview` answers requests only by `localhost` or an IP address, as `goodfellow dev` does, so a website can't point its own name at this computer to read it, `--network` or not; only this computer can open it, as before, unless `--network` is given, when other computers open it by this computer's IP address. WordPress exports write a Heading's alignment only where it's one WordPress has. WordPress exports, imports and pastes no longer stop at a linked file whose address has a stray `%` in it: they name it by its address as written.
