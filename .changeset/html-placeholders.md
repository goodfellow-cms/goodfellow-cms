An item's values go into HTML a block shows as written, such as Custom HTML's in a collection's page design, by where each placeholder sits. They were escaped only as text, which left a single-quoted or unquoted attribute's value open to more attributes, and an address such as `<iframe src="{video}">` open to `javascript:`. Now a value is escaped for any attribute, values that help spell the scheme of an address a browser follows or loads go in only where the whole address is a safe one, and a placeholder where no escaping makes a value safe (inside a tag outside an attribute's value, straight after a `<`, which is then written as text, in an `on…` attribute or `srcdoc`, in the address of a script, an `<object>` or `<embed>`, or `<base>`, in a script's `type` or `language`, in a script or style, or anywhere after an `<svg>` or `<math>`, whose markup browsers read by rules of their own) is left empty. The HTML is read as browsers read it: comments (never at `<!--!>`), `<!x>` and `<?x>` end where browsers end them, a tag's name ends at a `/`, only HTML's own whitespace ends a value, a text area's or title's content is text, and a script or style ends only at its own end tag, a script's not inside its `<!--<script>`, as the text is written with its values.
