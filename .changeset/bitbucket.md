Sites stored on Bitbucket Cloud, with `@goodfellow-cms/bitbucket`: sign-in with a repository access token, an Atlassian API token or Bitbucket's own sign-in, publishing as one commit that fails when someone else has published since, version history, drafts and pull requests, editors from the workspace, failed rebuilds explained, and the nightly update, scheduled changes and plugins' tasks through Bitbucket Pipelines, with Vercel putting the site online. `create-goodfellow --bitbucket` creates such sites, `goodfellow due` and `goodfellow-next due` take `--output`, and the token broker, the Claude extension and the admin panel know Bitbucket too.
