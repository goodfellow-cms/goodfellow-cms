Keyboard shortcuts in the admin panel: Ctrl+S (⌘S on a Mac) adds an editor's changes to a draft, never publishing them; Ctrl+Z, Ctrl+Shift+Z and Ctrl+Y undo and redo in the editors from the admin panel's own header too; Ctrl+K opens **Go to…**, which finds pages, items, collections, synced blocks and screens by name; and `?` lists them. The editor's frame tells the admin panel's page only which shortcut was pressed.
