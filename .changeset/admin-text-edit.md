Owners can edit the admin panel's words by hand on Site Settings → Admin panel languages: each language opens with every string's English beside what the admin panel shows, searchable and narrowed to what's not written, out of date, unusable or not read yet, with a mark for strings someone who speaks the language has read. English and Spanish open the same way, keeping only the words an owner changes over Goodfellow's own.
