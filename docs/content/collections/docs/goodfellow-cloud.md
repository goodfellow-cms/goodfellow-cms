**Goodfellow Cloud** is planned for the future, once enough organizations are interested. It isn't available yet, and there's nothing to pay for: everything these pages describe works today, for free.

## Goodfellow stays free

Goodfellow's core will always be free and open source, under the MIT license: the editor, the blocks, publishing, collections, languages, forms, imports and exports, and everything else these pages describe. Goodfellow Cloud would charge for convenience, never for what Goodfellow can do: everything it would run stays free to set up yourself, with the same documentation.

## What it would do

Some parts of a Goodfellow site are services that its owner puts online themselves, each on a free plan:

- the [sign-in service](/docs/sign-in-service), for **Sign in with GitHub**;
- a [token broker](/docs/token-broker), the safest place for editors to sign in;
- the [Claude connector service](/docs/claude-connector), for adding Goodfellow to Claude without a token;
- [media storage](/docs/media#media-kept-in-a-storage-service), for large files kept outside the repository.

Goodfellow Cloud would set these up when a site is created, run them and keep them up to date, so a new site needs nothing more than signing in, with no outside accounts to manage and nothing for a developer to change in the code. Later, it could host sites too.

Sites would still be kept in your own GitHub or GitLab account, and built there, so you'd own your content as you do today, and you could leave Cloud at any time, putting each service back in your own hands without losing anything.
