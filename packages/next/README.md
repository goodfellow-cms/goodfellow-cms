# @goodfellow-cms/next

Goodfellow pages and the admin panel in a Next.js App Router site, exported as static files, or with a server of its own that publishes for editors who sign in with the site's own sign-in (`@goodfellow-cms/next/server`). Links use `next/link` and images `next/image`.

Start from the Next.js starter: `npm create goodfellow@latest my-site -- --template next`.

[Goodfellow](https://github.com/goodfellow-cms/goodfellow-cms) is a website builder for people who aren't developers, with no server or database: pages are files in your own GitHub or GitLab repository, edited in a visual editor built on [Puck](https://puckeditor.com). To start a new site, run `npm create goodfellow@latest my-site`. See the [documentation](https://goodfellow-cms.github.io/goodfellow-cms/) for everything else.

More in the docs: [Next.js](https://goodfellow-cms.github.io/goodfellow-cms/docs/nextjs) and [Full-stack Next.js sites](https://goodfellow-cms.github.io/goodfellow-cms/docs/full-stack-nextjs).
