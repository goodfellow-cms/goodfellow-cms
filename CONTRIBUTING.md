# Contributing

Thank you for helping with Goodfellow.

Everything about changing this repository is in [AGENTS.md](AGENTS.md): the architecture rules, conventions, tooling and the checks to run before every commit. It's written for human contributors as well as coding agents, so please read it before you start.

- **Problems and ideas:** [open an issue](https://github.com/goodfellow-cms/goodfellow-cms/issues/new/choose) with one of the forms.
- **Security problems:** report them privately, as [SECURITY.md](SECURITY.md) says, never in a public issue.
- **Pull requests:** start from the checklist the pull request template gives you, and add a changeset (`pnpm changeset`) for any change to a published package.
